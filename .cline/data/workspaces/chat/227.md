## Selected problem

Problem Number:6
Problem Title:Open Source Decision Intelligence and Knowledge Recovery
Description: Important decisions are buried in long issue threads. The tool extracts decision, reasoning and rejected alternatives, with links back to the original comments.

Project
•⁠  ⁠Project name: DecisionTrace
•⁠  ⁠Tagline: Recover the decisions behind the code.
DecisionTrace is an open-source knowledge recovery tool for software projects. It analyses public project discussions, such as GitHub issues, pull requests, review comments and technical discussions, to recover engineering decisions and the reasoning behind them.

The system aims to identify accepted, rejected, deferred and unresolved approaches; explain the reasoning and alternatives recorded in discussions; preserve links and excerpts from the original sources; associate recovered decisions with relevant source files; and surface relevant historical context when a new pull request changes related code.

All recovered decisions must retain references to their original discussions so maintainers can verify the evidence. The system must distinguish evidence found in a source discussion from any model-generated interpretation and must not present unsupported conclusions as facts.
